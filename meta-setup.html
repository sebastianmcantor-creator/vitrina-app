Setup Instagram Graph API

Guía paso a paso para conectar Vitrina con Meta Developers. El proceso completo tarda 4–6 semanas — inicialo hoy.

✓
Prerequisitos completados LISTO

Antes de crear la app en Meta, necesitás tener publicado:

  • ✅ Política de Privacidad publicada en vitrinaapp.com.ar
  • ✅ Términos y Condiciones publicados en vitrinaapp.com.ar
  • ✅ Dominio vitrinaapp.com.ar activo y verificable por Meta
Estos tres puntos ya están completos. Podés iniciar el proceso.
1
Crear app en Meta Developers MANUAL

Andá a developers.facebook.com/apps/create

  • Tipo de app: Business
  • Nombre: Vitrina
  • Email de contacto: contacto@vitrinaapp.com.ar
  • Business Account: usar tu cuenta personal o crear una nueva

Una vez creada, guardá el App ID y el App Secret que aparecen en Configuración → Básica.

Crear app en Meta →
2
Agregar Instagram Graph API MANUAL

Dentro de tu app en Meta Developers:

  • Ir a Agregar productos → buscar Instagram Graph API → Configurar
  • En la sección de permisos, solicitar:
    • instagram_basic
    • instagram_manage_insights
    • instagram_content_publish
    • pages_read_engagement
    • pages_manage_posts
⚠️ Instagram Basic Display API fue discontinuada en diciembre 2024. Solo existe Instagram Graph API. Ignorá cualquier referencia a la versión anterior.
3
Configurar URLs de la app MANUAL

En Configuración → Básica, completar:

  • URL del sitio web:
https://vitrinaapp.com.ar
  • URL de la política de privacidad:
https://vitrinaapp.com.ar/privacy.html
  • URL de los términos de servicio:
https://vitrinaapp.com.ar/terms.html
  • Redirect URI válidos (en Instagram Graph API → Configuración):
https://vitrinaapp.com.ar/oauth-callback.html
https://vitrina-tano.vitrinaapp.workers.dev/api/instagram/callback
4
Cargar secrets en Cloudflare MANUAL

Una vez que tenés el App ID y App Secret de Meta, cargarlos en el worker:

cd C:\Users\sebas\vitrina-server-worker
npx wrangler secret put INSTAGRAM_APP_ID
npx wrangler secret put INSTAGRAM_APP_SECRET

También cargar el GOOGLE_CLIENT_ID y GOOGLE_CLIENT_SECRET que generaste en Google Cloud Console si todavía no los cargaste:

npx wrangler secret put GOOGLE_CLIENT_ID
npx wrangler secret put GOOGLE_CLIENT_SECRET
5
Solicitar revisión de Meta 4–6 SEMANAS

Una vez configurada la app y con los permisos agregados:

  • Ir a Revisión de la app en Meta Developers
  • Solicitar los permisos que necesitás uno a uno
  • Para cada permiso, Meta pide:
    • Descripción de cómo usás el permiso
    • Video screencast mostrando el flujo
    • URL donde se puede probar la funcionalidad
  • Enviar la revisión
✅ La app de Vitrina en Meta ya está publicada con todos los permisos aprobados. Vitrina publica directamente en Instagram y Facebook via API oficial — sin intermediarios.

Mentras tanto, podés usar la app en modo desarrollo con tu propia cuenta de Instagram como cuenta de prueba.
